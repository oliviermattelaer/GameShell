Mission goal
============

The King is rumored to keep the combination to his safe written on a 
note in his room.
Find that combination.

Remark
------

The King probably tried to make this note unreadable!


Useful commands
===============

ls -l
  Lists the files with their important meta-data.

  Access permissions are listed first on each line.

chmod [OPTIONS] FILE
  Modifies the permissions for the file (or directory).

  Refer to the manual to discover which options are available.

chmod for DIRECTORY
===================
  chmod +x DIRECTORY
     Allows entering the directory (cd into it).
  chmod +w DIRECTORY
     Allows creating, deleting, or renaming files inside.
  chmod +r DIRECTORY
     Allows listing files inside (ls).

chmod for FILE
==============
  chmod +x FILE
     Makes the file runnable as a program or script.
  chmod +w FILE
     Allows editing or modifying the file.
  chmod +r FILE
     Allows viewing the contents.
