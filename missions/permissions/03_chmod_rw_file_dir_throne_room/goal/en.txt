Mission goal
============

The safe in the throne room contains the king's crown.
Steal it and store it in your chest.

Also, the base of the crown is inscribed with a magical sequence of 
digits. Look at those digits and remember them.


Useful commands
===============

ls -l
  List the files with their important meta-data.

  Access permissions are listed first on each line.

chmod [OPTIONS] FILE
  Modify the permissions for the file (or directory).

  Refer to the manual to discover which options are available.

chmod for DIRECTORY
===================
  chmod +x DIRECTORY
     Allows entering the directory (cd into it).
  chmod +w DIRECTORY
     Allows creating, deleting, or renaming files inside.
  chmod +r DIRECTORY
     Allows listing files inside (ls).

chmod for FILE
==============
  chmod +x FILE
     Makes the file runnable as a program or script.
  chmod +w FILE
     Allows editing or modifying the file.
  chmod +r FILE
     Allows viewing the contents.
