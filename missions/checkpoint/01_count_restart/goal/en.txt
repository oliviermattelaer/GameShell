Mission goal
============

You are in the directory "~/Checkpoint/level1", which contains a small program, "count.py", that prints a number every second. Imagine it is a long computation: each number is one more step done.

  1. Run it with "python3 count.py".
  2. After a few numbers, stop it with Control-c.
  3. If you run it again, which number will it print first?

You can run it as many times as you want to find out. Then run "gsh check" and give your answer.


Remark
------

Each level starts in its own directory, "~/Checkpoint/levelN". If you move elsewhere, come back with "cd ~/Checkpoint/levelN".


Useful commands
===============

python3 SCRIPT
  Run the python script SCRIPT.

Control-c
  Stop the program running in the terminal. (Control-c sends the signal SIGINT, "interrupt", to the program.)
