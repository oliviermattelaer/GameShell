Mission goal
============

Provide information to git to identify yourself.
This include
  - Your name
  - Your email


Useful commands
===============

git config --global user.name "YOURNAME"
git config --global user.email "NAME.LASTNAME@example.com"
~~ Without --global, the setting only applies to the repository you are
~~ currently in, and you would have to repeat it for every new project.
~~ With --global it applies to every repository on the machine, which is
~~ what this mission expects.
~~ Note that inside GameShell, --global only writes to the game's own
~~ configuration file: your real ~/.gitconfig is never modified.
