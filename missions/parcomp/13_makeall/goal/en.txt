Mission goal
============

For this mission, we will look at the case where we have both
multiple data files and multiple commands, and we suppose we have
to use intermediate files. 

This is the typical usecase for the Make command. The two rules you
wrote tell `make` how to build one file; what the `Makefile` still
misses is a target saying what has to be built in the end:

    # Build everything
    all: d1.res d2.res d3.res d4.res

Add it above the two rules: the first target of a `Makefile` is the
one `make` builds when it is called without argument.

Then run it, once purely sequentially, then once using multiple
programs in parallel, and measure the time it takes to complete.

Useful commands
===============

make
  without arguments, `make` will look for a file named `Makefile`
  with instructions on which program to run based on which input
  files to produce which output files. With the `-j N` argument,
  `make` will run `N` programs in parallel when possible.
  
Remarks
-------

The `make` command will only re-run the commands that are needed
to create the missing outputs. Therefore, two consecutive runs 
of make will lead to the second one doing nothing. To force a
full re-run, use the `-B` argument.
