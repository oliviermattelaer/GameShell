Mission goal
============

One rule is not enough: the `.tmp` files are only half of the
work, they still have to go through `./upper.sh` to become the
`.res` files we are after.

The goal of this mission is to add a second rule to your
`Makefile`, written on the model of the first one: it builds a
`.res` file from the `.tmp` file of the same name, by running
`./upper.sh` on it.

Once it is written, build the result of the second data file with

    make d2.res

Useful commands
===============

make TARGET
  build TARGET, following the rules of the `Makefile` of the
  current directory

Remarks
-------

In the command of a rule, `make` replaces `$<` by the first file
the target is built from, and `$@` by the target being built. For
`d2.res`, `$<` is therefore `d2.tmp` and `$@` is `d2.res`, so the
command `./upper.sh $< $@` runs

    ./upper.sh d2.tmp d2.res

Writing the command with `$<` and `$@` rather than with those two
names is what makes the rule work for the four data files, and not
only for the second one.

Note that you never asked for `d2.tmp`, and that no rule mentions
`d2.txt` or `d2.res` by name. `make` works out on its own that
`d2.res` is built from `d2.tmp`, which is built from `d2.txt`, and
runs the two commands in the right order. This chain is what will
let it run several of them at the same time in the next mission.

Here again, the line holding the command must start with a real
tabulation, not with spaces.
