Goal of the mission
===================  


In this mission the goal is to create your own collection of spells, so that you can activate multiple spells at once with a name of your choice.

Create a collection with the following modules:
    R/4.2.2-foss-2022b
    netCDF/4.9.0-gompi-2022b
    Java/11.0.20
and name it VESUVE.

First, you will need to remove all the modules that you have loaded.

These modules belong to the 2022b release, so after the purge you need to switch to that release ("module load releases/2022b", as in the previous missions) before loading them.

Useful commands
===============

module purge
  remove all the modules that are currently loaded. 
  Sticky modules (releases/...) stay loaded.


module spider NAME/VERSION
  gives the details on the other modules to be loaded to get access to that particular module


module load XXXXXX
  (shortcut: ml XXXXXX)
  load the specified module / release 


module save XXXXXX
  save the currently loaded modules as a "collection" named XXXXXX


module restore XXXXXX
  load back all the modules of the collection XXXXXX


module savelist
  list your saved collections


Useful trick
============

If you want to arrive on the cluster and have a collection activated by default, you can use
module save 

All the modules currently loaded will be available by default at each new connection to the cluster.
