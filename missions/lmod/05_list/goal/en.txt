Goal of the mission
===================  

As you know, programs depend on each other, so when you load a program, you also automatically load its dependencies.
For this mission, load the most recent version of Python and determine the number of modules that have actually been loaded.


Useful commands
===============

module spider NAME
  list all possible versions of the programs whose name contains NAME

 
module spider NAME/VERSION
  gives the details on the other modules to be loaded to get access to that particular module


module load XXXXXX
  (shortcut: ml XXXXXX)
  load the specified module / release 


module list
  (shortcut: ml)
  print all the currently loaded modules
