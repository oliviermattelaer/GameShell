Goal of the mission
===================  

Good job! 
Now your goal is to be able to load that old version of Python2.

For that you will need to change the section of the library you are in. This can be done with the same command as seen before (e.g. module load releases/2021b). After that you should be able to load that version of Python.

To check which section you are in now, you can simply run "module av": its output is split into the various sections available to you (on top of the releases section, you always have access to other sections of the library). 

When the python2 spell is available, you can simply run the "gsh check" command. You do not have to answer any question for this level. 

Useful commands
===============

module spider NAME
  list all possible versions of the programs whose name contains NAME

module spider NAME/VERSION
  gives the details on the other modules to be loaded to get access to that particular module

module load XXXXXX 
  (shortcut:  ml XXXXXX)
  load the specified module / release 

module av NAME
  list the available programs whose name contains NAME
  a (L) indicates that the module is currently loaded.
