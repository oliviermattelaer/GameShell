Goal of the mission
===================  


Good job! 
Did you know that "module av / module avail" does not show the full list of modules/programs that you can use?
It only shows one section (named releases) of the full library. 
Careful, you cannot have spells/programs from two different sections loaded in your spell book at the same time.

The goal of this mission is to find how many different versions of Python are available in the FULL library and not only in the current section (release) that you are in.

Useful commands
===============

module av NAME
  list the available programs whose name contains NAME

module spider NAME
  list all possible versions of the programs whose name contains NAME

  
module spider NAME/VERSION
  gives the details on the other modules to be loaded to get access to that particular module
