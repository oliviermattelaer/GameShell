Goal of the mission
===================  

Now that you have found the correct default version, you can ask the librarian to put that spell in your spellbook, so that you can cast it.

For this mission, your goal is to activate the default version of the "python" spell.
To pass "gsh check", you will need to provide the place where this spell is stored in the library (path of the executable). You can use the command 'which python' for that.  

Useful commands
===============

module av XXXXX
  list the available programs whose name contains XXXXX
  if more than one program with the same name is present, a (D) indicates the default version.


module load NAME
  activate a given program (so that you can use its commands)
  - NAME can be just the name (like "module load Python"): the default version is then loaded
  - NAME can also be a name and a version number, to load that specific version (like "module load Python/3.12.1")

which NAME
   print the full path of the executable "NAME"

WARNING:
=======

For both the module and the which commands, NAME is case sensitive, but the case sometimes differs (Python for the module and python for the executable).


Technical information
=====================

In order to launch a program, you need several pieces of information, including:
- where the executable is
- where the dependencies are
This information is typically stored within environment variables ($PATH, $LD_LIBRARY_PATH, ...). The module command will technically add/clean these environment variables, allowing you to have an easy way to handle such variables.
